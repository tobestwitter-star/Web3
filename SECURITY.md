# Security and scope policy

Web3 BugHunter is for authorized security research only.

- Only analyze and test targets explicitly listed as in-scope by a bounty program.
- Public discovery does not grant authorization to test a target.
- Never automatically submit reports.
- Every finding must remain `UNVERIFIED — HUMAN REVIEW REQUIRED` until a human independently reproduces it.
- Do not store API keys, credentials, private keys, wallet seed phrases, or private connection strings in the repository.
- Use environment variables for service credentials.

The project's $2,000+/month objective is an aspirational productivity target, not an earnings guarantee.
